# Évora Academy 🎓

**Seu espaço acadêmico, organizado no seu ritmo.**

O Évora Academy é um planner acadêmico desenvolvido para ajudar estudantes a organizar a rotina de estudos, acompanhar atividades, controlar avaliações e visualizar sua evolução durante o semestre.

Com uma interface escura em tons de roxo e lilás, reúne ferramentas de organização acadêmica em um só lugar.

## ✨ Funcionalidades

### 📊 Dashboard
- Visão geral do progresso acadêmico.
- Acompanhamento de atividades pendentes e concluídas.
- Identificação de entregas próximas e atrasadas.
- Resumo das próximas avaliações.
- Acesso rápido às principais áreas do planner.

### 📅 Organização e planejamento
- **Minha semana:** visualização das atividades de segunda a domingo.
- **Meu calendário:** visualizações mensal, semanal e diária.
- Cadastro de trabalhos, tarefas e atividades.
- Definição de prazos, horários, prioridades e status.
- Checklist de etapas para acompanhar tarefas maiores.

### 📚 Área acadêmica
- Cadastro e organização de disciplinas.
- Controle de provas e avaliações.
- Cronograma de sessões de estudo.
- Registro de notas e pesos.
- Cálculo de médias e projeção de notas necessárias.
- Organização de materiais de estudo com links.
- Anotações vinculadas às disciplinas.

### 🎯 Produtividade e rotina
- Metas mensais com acompanhamento de progresso.
- Controle de hábitos.
- Checklist diário.
- Temporizador Pomodoro configurável.
- Anotações semanais.

### ⚙️ Personalização e dados
- Personalização do nome de exibição.
- Configuração da escala de notas e média desejada.
- Ajuste dos tempos de foco e descanso do Pomodoro.
- Pesquisa geral e filtros para localizar registros.
- Exportação e importação de backups em JSON.
- Opção de impressão de páginas e calendários.

## 🖥️ Tecnologias

O projeto foi desenvolvido utilizando:

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização e layout responsivo.
- **JavaScript** — funcionalidades e interações.
- **LocalStorage** — armazenamento dos dados no navegador.

O projeto funciona diretamente no navegador, sem necessidade de instalação de dependências ou configuração de servidor.

## 🚀 Como utilizar

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Comece cadastrando suas disciplinas e organizando suas atividades.

Não é necessário instalar programas adicionais para utilizar o planner.

## 💾 Armazenamento e backup

Os dados são salvos localmente no navegador por meio do `LocalStorage`.

**Importante:** os dados não são sincronizados automaticamente entre dispositivos ou navegadores.

Para preservar suas informações:
1. Acesse **Configurações**.
2. Clique em **Exportar backup JSON**.
3. Guarde o arquivo gerado em um local seguro.
4. Para recuperar seus dados, utilize a opção **Importar backup**.

Recomenda-se exportar backups periodicamente.
